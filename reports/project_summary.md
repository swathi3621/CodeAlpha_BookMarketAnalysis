# Project Summary

## Project
Book Market Analysis using Web Scraping, EDA and Data Visualization

## Task 1 - Web Scraping
A Python scraper uses Requests and BeautifulSoup to navigate the Books to Scrape demo website. It collects product title, price, availability, rating, category and product URL from multiple pages and saves the result as CSV.

## Task 2 - EDA
The analysis checks:
- dataset dimensions
- data types
- missing values
- duplicate records
- descriptive statistics
- price range
- expensive products
- category distribution
- rating distribution
- stock status
- possible relationship between price and rating

## Task 3 - Data Visualization
The project generates:
- price distribution
- top 10 expensive books
- stock-status chart
- category distribution
- rating distribution
- price-versus-rating scatter plot

## Conclusion
The project demonstrates an end-to-end data analytics workflow: collecting raw web data, transforming it into a structured dataset, exploring data quality and patterns, and communicating findings through visualizations.
